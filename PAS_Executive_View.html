Link the shared folder your clinics sync their rollup files into — or drag the files straight onto this box.

  1. Each clinic opens PAS_Quality_Dashboard.html, imports its own Epic exports, and clicks ⬇ Export for executive view (data).
  2. That saves a small .pasq.json rollup — counts only, no patient identifiers.
  3. Name the file for the clinic — Aspen Clinic.pasq.json. The file name is the clinic here; Epic's sub-clinics inside it are rolled up into that one clinic. Dates and words like rollup or export in the name are ignored.
  4. Everyone drops their file into the same synced folder (OneDrive, SharePoint or a network drive).
  5. Click Link Folder above and pick that folder. Press 🔄 Update any time to pull in new files.

Link Folder needs Chrome or Edge. In Safari or Firefox, drag the files onto this box instead.
